Simply install these files into a directory with "read & write" permissions:
  EyeChat.pl
  EyeChat.conf
  EyeChat.lang

In most cases, installing them into a cgi-bin directory will do, but you can opt to 
install them into a directory called "EyeChat" as well and it might be easier to keep 
things organized that way.  Wherever you install them, make sure that you also create 
these sub-directories in the same directory as those files:
  chatarchives
  chatfiles
  chatvis
  chatplugins
  emoticons
  profiles

Open up each file and edit the paths accordingly.  Once all the paths are edited, the
script should run without further editing.
